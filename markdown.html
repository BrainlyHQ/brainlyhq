Markdown Quick Reference

Headers

Create headings by adding hashtags followed by space at the start of a line.

# Large Header
## Medium Header
### Small Header

Basic Formatting

Quickly apply basic typographic styling using native asterisks and underscores.

**Bold Text**
*Italic Text*
__Underlined Text__
~~Strikethrough Text~~

Spoilers

Hide sensitive texts or jokes. Users can click the black bar on Discord to reveal it.

||Click to reveal this secret!||

Lists & Quotes

Organize data with bullet points or high-priority inline blockquotes.

- Bullet list item 1
- Bullet list item 2
> This is an important quote block
