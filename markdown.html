Markdown Quick Reference

Headers & Subtext

Add header hash symbols or the subtext command at the start of a line.

# Large Header
-# This is small subtext

Basic Formatting

Quickly apply basic typographic styling using native asterisks and underscores.

**Bold Text**
*Italic Text*
__Underlined Text__
~~Strikethrough Text~~

Spoilers & Spacers

Hide secret texts or insert an empty spacer line to make gaps between blocks.

||Secret||
_ _

Lists & Quotes

Organize data with bullet points or high-priority inline blockquotes.

- Bullet list item 1
> This is an important quote block
